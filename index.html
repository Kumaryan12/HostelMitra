About HostelMitra

Built for NIT Goa, HostelMitra streamlines maintenance requests and improves campus life with clarity, speed, and accountability.

Why HostelMitra?

  • ✔ File complaints in seconds—no queues, no paperwork.
  • ✔ Choose Public (visible to all) or Private (admin-only).
  • ✔ Vote on common issues to help admins prioritize effectively.
  • ✔ Admin has filters for Visibility and Status with real-time updates.
  • ✔ Secure authentication with NIT Goa emails and role-based routing.

Which emails are allowed for student login?

Student login is restricted to @nitgoa.ac.in accounts for security.

What’s the difference between Public and Private complaints?

Public complaints are visible to all students (and can be upvoted). Private complaints are visible only to admins.

How soon do updates appear?

All updates are real time via Firestore snapshots—no page refresh needed.
